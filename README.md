# RL for Space — Project

A personal reinforcement-learning project with an application in space.
Scope, method, and results are documented as the project develops.

> **Status:** scoping. Candidate projects are under `docs/proposals/`; the
> chosen project and its report will be written up here.

## Layout

```
docs/
  00_brief.md        # goal, constraints, timeline
  01_context.md      # my RL + space-domain background (why certain projects fit)
  rubric.md          # what "subpar" vs "excellent" means for this project
  proposals/         # candidate projects + feasibility audit
```

## Environment

- Python 3.11
- Dependencies pinned in `requirements.txt` once the method is fixed.
